# Lion y Emir · Presskit 3D

Presskit y plan de trabajo del dúo urbano Lion y Emir (reggaetón 2012 y sexy drill). Web estática con recorrido 3D por scroll hecho con Three.js.

- `index.html`: página
- `scene.js`: escena 3D y animaciones
- `photos.js`: fotos incrustadas

Three.js y las tipografías se cargan desde CDN, así que hace falta conexión.
